    挟将のルール

    オセロの盤と挟み方で、数値の違う持ち駒を置いて体力を削り合う。相手の体力を 0 にするか、終局時に体力で上回れば勝ち。

    準備

    • 8×8 の盤。初期配置はオセロと同じで、中央の 4 駒はすべて歩（1）
    • 体力: 先手 65 / 後手 66
    • 持ち駒（両者同じ・公開）: 歩1 ×14 / 銀2 ×10 / 金3 ×6 / 飛5 ×2

    手番

    1. 持ち駒から 1 個選び、オセロのルールどおりに置く（相手の駒を挟めない場所には置けない）
    2. 攻撃: 相手の体力を「返した駒の最大値 ＋ 返した枚数 ÷ 4（切り捨て）」減らす
    3. 回復: 挟んだ方向ごとに「置いた駒と、反対側の端の自分の駒の低い方 − 1」を求め、いちばん大きい 1 方向分だけ回復（0 未満は 0）
    4. 返された駒は色だけ変わり、数値はそのまま残る

    回復の早見表

    低い方歩 1銀 2金 3飛 5
    回復0124

    例: 金を置いて相手の歩・銀・金を返し、反対側の端が自分の銀 → 攻撃 3（最大値 3 ＋ 3÷4＝0）、回復 1（min(3, 2) − 1）。

    決着

    • 体力が 0 以下になった時点でそのプレイヤーの負け
    • 盤が埋まるか両者とも置けなくなったら終局。体力の多い方が勝ち → 同じなら石の数 → それも同じなら引き分け
    • 置ける場所がない、または持ち駒が尽きたらパス（攻撃も回復もなし）

    追加ルール: 角（対局設定で ON）

    • 持ち駒の歩 2 個を角 2 個に差し替える。体力は先手 65 / 後手 65
    • 角は盤上では数値 1（回復は歩と同じ 0）
    • 角を置いた手の攻撃は「返した駒の最大値 × 2 ＋ 返した枚数 ÷ 4」

    画面の操作

    • 持ち駒を選ぶと置けるマスに印が出る。マスにカーソルを乗せると、その手の攻撃・回復と返る駒を予測表示する
    • スマホでは 1 回目のタップで予測、同じマスを 2 回目のタップで確定
