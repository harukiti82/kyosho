    あなたの手番

    挟将のルール

    オセロの盤で、挟んだ相手の駒を取って自分の持ち駒にする二人対戦。取った駒の数字が相手へのダメージになる。

    ルール（これで全部）

    1. 持ち駒を空いているマスならどこにでも置ける（挟めなくても置ける）
    2. 置いた駒と自分の駒で一直線に挟んだ相手の駒（オセロと同じ 8 方向・連続した列）は盤から取り、自分の持ち駒にする（数字はそのまま）
    3. 取った駒の数字の合計が相手へのダメージ
    4. 体力が 0 以下になったら負け。挟まれる位置へ自分から置いても取られない（取るのは置いた側だけ）

    準備

    • 8×8 の盤。中央の 4 駒は歩（オセロと同じ配置）
    • 持ち駒（両者同じ・公開）: 歩1 ×8 / 金3 ×4 / 飛5 ×2
    • 体力: 両者 20

    例

    黒が a1 に置き、b1 の白の歩1・c1 の白の金3 を d1 の黒と挟んだ → 歩と金を取って黒の持ち駒にし、白に 1＋3＝4 ダメージ。

    決着

    • 体力が 0 以下になった時点で負け
    • 総手数 80 手（各 40 手）で打ち切り。体力の多い方の勝ち、同じなら引き分け
    • 持ち駒が尽きたらパス。両者とも尽きたら終局し、体力で判定

    画面の見方

    • 置く駒を持ち駒から選ぶ（最初は歩が選ばれている）
    • の付いたマスは、置くと何か取れるマス
    • マスにカーソルを乗せる（スマホは 1 回タップ）と、取れる駒が 赤枠で光り、ダメージを表示。スマホは同じマスをもう一度タップで置く
    • ! の付いた自分の駒は、相手が次の 1 手で取れる駒
